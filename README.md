# Wintech CRM — APK downloads

Offline billing & CRM app for Android (Flutter).

## Install
1. Open the **latest release** and download the APK
2. Open the downloaded APK on your Android phone
3. Allow "Install unknown apps" for your browser when asked
4. Tap **Install**

## About
Invoices + Quotations with GST, company logo & watermark in PDFs,
dashboard graphs, daily/weekly/monthly/yearly reports (PDF/Excel/CSV),
offline backup/restore, local signup/login with licence keys.
